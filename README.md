# РСХБ-Страхование · Золотая осень — 2026

Самостоятельный статический лендинг по `tz-ai-agent-landing-zolotaya-osen-2026.md`.

## Просмотр

Запустите из корня проекта `python3 -m http.server 4173 --directory dist` и откройте http://localhost:4173/.

## Изменения

- `dist/index.html` — все тексты, даты, адресные поля и социальные ссылки. Адрес — в `dl.address`.
- `dist/styles.css` — типографика, цвета, адаптивность и анимация.
- `dist/script.js` — необязательное появление блоков. Без JavaScript контент остаётся виден.
- `dist/assets/` — оптимизированные изображения, локальные шрифты и иконки. Для первого экрана подключён отдельный рендер стенда без людей (`stand-1600-no-people.webp` и `stand-800-no-people.webp`); исходная версия сохранена рядом.

Для размещения на rshbins.ru скопируйте содержимое `dist/` в выбранную папку сайта. Сборка, серверный код и внешние зависимости не нужны; все пути относительные. Проверяйте MIME-типы CSS, JS, SVG, WebP и TTF. Номер зала и ориентир необходимо уточнить перед печатью листовки.

## Материалы

Рендер и фирменные изображения предоставлены заказчиком. Рендер кадрирован без полей PDF и отметки согласования. Изображения оптимизированы в WebP; оригиналы сохранены. Golos Text (SIL OFL) размещён локально, лицензия — `dist/assets/Golos-OFL.txt`. Иконки — Phosphor Icons 2.1.1, MIT.

Страница не отправляет данные, не использует cookies, аналитику, формы или QR-код.
